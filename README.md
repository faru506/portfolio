# Farooq Shaik Portfolio

Modern responsive portfolio website for Farooq Shaik, built with React, Vite, TailwindCSS, and lucide-react icons.

## Features

- React functional components and hooks
- TailwindCSS styling with class-based dark mode
- System theme default with localStorage persistence
- Sticky responsive navbar with active section highlighting
- Mobile hamburger navigation
- Hero, About, Skills, Projects, Experience, Contact, and Footer sections
- Scroll-to-top button
- Resume PDF download and profile illustration
- Glassmorphism surfaces with smooth hover and entrance transitions

## Run Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
